# 0.112 → 0.113 — the values form, `reader.get` in it, `resolve` on the reader, and the storage DTO verbs become `toStored` / `fromStored`

Five changes. The **values form** lands: `reader.values()` reads a document as
plain values and `writer.setValues` writes them back, at document and card
scope. `reader.get` now **answers in that form**: a field whose content sits
inside an array or an object reads as text rather than as stored content
objects, and a present-null reads `null` — the one break a type checker will not
report. `quill.resolve(doc)` **moves onto the reader** as `reader.resolve()`.
And the storage DTO verbs are **renamed**: `toJson` / `fromJson` /
`tryFromJson` / `loadJson` become `toStored` / `fromStored` / `tryFromStored` /
`loadStored` (Python: `to_stored` / `from_stored` / `try_from_stored`).
And a Python `edit::*` diagnostic **anchors at its `DocPath`**, the spelling
WASM already carried.

If your host never persists a `Document`, never calls `quill.resolve`, never
reads a composite content-bearing field or a present-null, and never routes on
a Python diagnostic's `path`, there is nothing to do.

## The three forms

A document has three forms, one per question:

| Form | Definition | Read | Write |
|---|---|---|---|
| **stored** | the at-rest value, verbatim, quill-free | `doc.getStored(addr)`, `doc.toStored()` | `doc.storeField(addr, v)`, `Document.fromStored()` |
| **values** | stored, with every content leaf decoded to its codec's text | `reader.get(name)`, `reader.values()` | `writer.set(name, v)`, `writer.setValues(v)` |
| **resolved** | values, blank-filled and render-coerced, each cell tagged with its rung | `reader.resolve()` | — |

A read never coerces a scalar: `qty: "3"` is `"3"` in `get` and `values()` and
`3` only in `resolve()`, because canonicalizing is what a write does. That is
what makes `reader.get(name)` equal `reader.values().fields[name]`.

## Why the storage verbs move

Both surfaces now carry two whole-document JSON views: the storage DTO, lossless
and frozen per schema version, and the values form, which reads content fields
as markdown for a consumer to edit. Both are JSON, so the encoding is the one
thing that cannot tell them apart. `toJson` named the encoding.

"The verb carries the lane" already governs the write surface, and `getStored`
already applies it to the read surface — the verbatim read is the read echo of
`store`, distinct from the interpreted `reader.get`. `toStored` / `fromStored`
extends that family to the document level: "stored" is the at-rest form
throughout Quillmark, and it is exactly what the DTO carries.

The **adjective**, not the bare verb. `store` is one of the three field-write
lanes (`store` verbatim / `set` typed / `overwrite`·`revise`·`apply` content), so
a `doc.store()` / `Document.load()` pair would collide with a rule that is
already load-bearing. `toStored` completes the family; `store()` would break it.

The old names are removed rather than aliased. An alias that keeps working while
the neighbouring view means something else is the one failure neither TypeScript
nor Python reports.

## Migrate: rename the storage call sites

Signatures, arguments, return types, and thrown errors are unchanged.

| 0.112 | 0.113 |
|---|---|
| `doc.toJson()` | `doc.toStored()` |
| `Document.fromJson(blob)` | `Document.fromStored(blob)` |
| `Document.tryFromJson(blob)` | `Document.tryFromStored(blob)` |
| `doc.loadJson(blob)` | `doc.loadStored(blob)` |
| `doc.to_json()` (Python) | `doc.to_stored()` |
| `Document.from_json(blob)` (Python) | `Document.from_stored(blob)` |
| `Document.try_from_json(blob)` (Python) | `Document.try_from_stored(blob)` |

```js
// 0.112
const blob = doc.toJson();
const restored = Document.fromJson(blob);
const maybe = Document.tryFromJson(blob);   // undefined when not a DTO

// 0.113
const blob = doc.toStored();
const restored = Document.fromStored(blob);
const maybe = Document.tryFromStored(blob);
```

```python
# 0.113
blob = doc.to_stored()
restored = Document.from_stored(blob)
maybe = Document.try_from_stored(blob)      # None when not a DTO
```

## Migrate: `quill.resolve(doc)` → `reader.resolve()`

The shape is unchanged. A verb that needs a schema lives on the cursor, and
the two whole-document reads sit together.

```js
// 0.112
const states = quill.resolve(doc);

// 0.113
const states = quill.reader(doc).resolve();
```

## New: the values form

`reader.values()` reads a document as plain values — the fields it carries
with every content leaf as its codec's text and everything else as stored,
bodies as markdown, `$ext` (`null` when none) — and `writer.setValues(values)`
(`writer.set_values` in Python) writes that shape back. `reader.card(i).values()`
and `writer.card(i).setValues(values)` are the same pair for one card.

```js
const values = quill.reader(doc).values();
// { fields: { subject: "Hello **world**", paragraphs: ["Para **one**"] },
//   body: "Body prose.",
//   cards: [ { kind: "line_item", fields: { … }, body: "…", ext: null } ],
//   ext: { app: { k: 1 } } }
values.fields.subject = "Goodbye *world*";
quill.writer(doc).setValues(values);
```

It is **sparse** (an absent field is an absent key, never its `default:`) and
**total** (it never throws). On the way in, **an absent axis is untouched and a
present one is replaced**: `setValues({ fields: { subject: "x" } })` rewrites
the main fields and leaves the body, the cards and `$ext` alone; `cards` is the
whole card list; `ext: null` removes `$ext` and `{}` stores an explicit empty
one; an `undefined` member reads as absent. Writing back an unedited read is a
byte no-op, so a read-edit-write cycle does not disturb the cells it did not
touch. It is a projection, not a storage format: keep persisting with
`toStored`. See
[SCHEMAS.md](https://github.com/borb-sh/quillmark/blob/main/prose/canon/SCHEMAS.md)
§ "The values form" for the full loss list.

## Breaking: `reader.get` answers in the values form

`reader.get` dispatched on the *field's* declared type, so a field whose
content sat one level in returned the stored content objects while a bare
`richtext` field returned markdown. It now projects at every content leaf, and
core's `ReadValue` enum is gone: `get` returns the plain value.

| Field | 0.112 | 0.113 |
|---|---|---|
| `array<richtext>` | `[{text, lines, marks, islands}, …]` | `["Para **one**", …]` |
| `object` with a `richtext` property | `{motto: {text, …}, code: "9"}` | `{motto: "Fly **fight**", code: "9"}` |
| variant cells | the stored content objects | each cell at its own codec |
| a present-null content field (`subject:`) | `""` | `null` (`None` in Python) |
| `richtext` / `plaintext` whole-field | markdown / literal text | unchanged |
| a type tree with no content leaf | verbatim | unchanged |

A leaf that does not decode still throws `edit::field_decode`, now anchored at
the element (`main.paragraphs[1]`). `reader.getContent` / `getContentAt` are
unchanged — they answer with the `Content`, where `get` projects. **Migrate:** a
host reading a nested content object off `reader.get` either takes the text it
now gets, or switches that call to `reader.getContentAt(field, path)`; a host
that treated a present-null content field as `""` reads `null` now.

## Breaking (Python): an `edit::*` diagnostic anchors at its `DocPath`

`Diagnostic.path` carried three spellings for one refusal, so nothing could
route on it: `writer.set` minted none, `writer.set_all` the bare field name,
`writer.set_values` the rooted path. Every writer and reader verb now anchors
where WASM already did — the rooted `DocPath` of
[ERROR.md](https://github.com/borb-sh/quillmark/blob/main/prose/canon/ERROR.md)
§ "Document-model paths".

| Call | 0.112 | 0.113 |
|---|---|---|
| `writer.set("stray", "x")` | `None` | `"main.stray"` |
| `writer.set_all({"stray": "x"})` | `"stray"` | `"main.stray"` |
| `writer.card(0).set("stray", "x")` | `None` | `"cards.quotes[0].stray"` |
| `doc.set_card_kind(9, "quotes")` | `None` | `"cards[9]"` |
| `writer.set_values({"fields": {"stray": "x"}})` | `"main.stray"` | unchanged |

**Migrate:** a host matching `d.path` against a bare field name matches
`main.<field>` now, or reads the name off `d.args["field"]`, which carries it
unescaped. `writer.add_card` keeps its keys: the card is committed before it
joins the document, so a rejected kind, body or field is `$kind` / `$body` /
the bare name, as in WASM.

## Unaffected

- **Stored blobs.** The wire format, the `schema` tag
  (`quillmark/document@0.112.0`), and byte-determinism within a version are
  untouched. A row written by 0.112 loads in 0.113 and back.
- **`storageVersionOf` / `currentStorageVersion`** (and their Python twins) keep
  their names: they already say storage.
- **Core (Rust).** `Document` serializes through `#[serde(into / try_from)]` and
  callers use `serde_json` directly, so there is no verb to rename. The
  collision was a WASM/pyo3 artifact of fusing the DTO onto the one `Document`
  handle, as `getStored`'s was. `Quill::resolve` stays as the core producer
  beside `TypedReader::resolve`.
- **`toMarkdown` / `fromMarkdown`**, `equals`, `clone`, and every mutator.
- **`quill.validate` / `quill.conform` / `quill.parse`**, which stay on the
  quill as its ingestion and verdict verbs.
