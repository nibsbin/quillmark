# 0.126 → 0.127 — an acroform quill's field spec is `Form.yaml`, and a field box that shows nothing fails to open

**An acroform quill's field spec is `Form.yaml`, capitalized as `Quill.yaml`
is.** A quill holding `form.yaml` fails to open as
`acroform::legacy_form_yaml`, and so does one holding both. Rename the file to
`Form.yaml`; its contents are valid as they are. No acroform quill opens on both
0.126 and 0.127: 0.126 reports a `Form.yaml` quill as
`acroform::missing_form_spec`. Declare `requires: ">=0.127"` in `Quill.yaml` so
an older engine names the release it needs. On a case-insensitive file system,
rename with `git mv form.yaml Form.yaml`: a plain `mv` changes the name on disk
but not in git, so a clone elsewhere still holds `form.yaml`.

**An acroform quill whose `Form.yaml` gives a field a `rect` with no width or
height, or one wholly off its page, fails to open as
`acroform::invalid_field_rect`, where it opened and rendered with that field's
value nowhere to be seen.** The error names the field and its rect. A box that
only crosses its page's edge still loads. Give the box a positive `w` and `h`
on its page, or drop the field from `Form.yaml`.

| Break | Surface | Action |
|---|---|---|
| An acroform quill's field spec is `Form.yaml`; `form.yaml` fails to open as `acroform::legacy_form_yaml` | acroform quill open | `git mv form.yaml Form.yaml`, and declare `requires: ">=0.127"` |
| A `Form.yaml` field box with no area, or wholly off its page, fails to open as `acroform::invalid_field_rect` | acroform quill open | Fix the field's `rect`, or drop the field |
