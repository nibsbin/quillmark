# 0.124 → 0.125 — regions come from what a plate declares, one decline code, and a typed set reports its drops

Each section below is one concern, those whose breaks no type checker reports
first, and the table closing the guide lists every break.

## A plate's own print of a value surfaces no region

**`#data.subject`, `#upper(data.subject)`, a `let` alias's read and every other
value the plate prints itself render as before but surface no region and
answer no click.** 0.124 scanned the plate's syntax for `data` reads and
windowed each one; that scan is gone. Regions come from three producers, each
one the plate declares:

- ink the helper generates: a `richtext` or `plaintext` value, and any field
  printed through `qm.ink`;
- a `qm.region` claim on ink the plate composes;
- a form widget bound with `field:`.

Print a field through `qm.ink` to keep its click target, or claim composed ink
with `qm.region`. `quillmark check --regions ./my-quill doc.md` lists the
filled fields no click reaches, and `session.coverage()` returns the same list.

## A claim takes the text it brackets, and no page chrome

**A `qm.region` claim takes the text between its markers that Typst draws with
no source position of its own, such as a string cast to content inside a
function argument (`text(size: 9pt, "LIT")`) and a list's bullets, where 0.124
left them unclaimed.** An underline or strike stroke stays with the content it
decorates. A claim open across a page break takes none of the header, footer
or background it crosses, where it claimed them, and not the page number. A
claim placed inside a header or footer still takes that marginal's ink.

## `$ink` is gone, and `$path` is on every typed dictionary

**No dictionary carries `$ink`; `qm.ink(dict, key)` reads ink by address.**
`data`, every card and every typed dictionary or table row carry `$path`,
where a dictionary carried it only beside an `$ink` or a matrix. A plate
comparing two dictionaries, walking `keys()` or spreading a row into a call
sees `$path` on dictionaries that had no `$` key in 0.124; skip `$`-prefixed
keys there. A matrix's own dictionary still carries none.

## The unclosed-claim warning is renamed

**A claim whose close never reaches a frame warns `typst::unclosed_region`,
where it warned `typst::unclosed_field_region`.** Route on the new code.

## The helper is a module imported as `qm`

**A plate imports the helper as a module, at version 0.2.0:**

```typst
#import "@local/quillmark-helper:0.2.0" as qm
```

Every other form fails the render with `typst::helper_import` at the import
line: `: *`, `: data, ink`, a bare `#import`, and the 0.1.0 version. The name
is the plate's to choose; `qm` is the convention. Every member is read through
it, and two are renamed:

| 0.124 | 0.125 |
|---|---|
| `data` | `qm.data` |
| `ink(x).f`, `ink(x).at(k)` | `qm.ink(x, "f")`, `qm.ink(x, k)` |
| `display("addr", ..args)` | `qm.ink(qm.data, "addr", ..args)` |
| `display(x, "f", ..args)` | `qm.ink(x, "f", ..args)` |
| `display(card.at("$path") + "f", ..)` | `qm.ink(card, "f", ..)` |
| `field-region(f, body)` | `qm.region(f, body)` |
| `roster`, `form-field`, `signature-field`, `elements`, `tasks` | the same name under `qm.` |

A plate that wants the bare name binds it: `#let data = qm.data`.

`qm.ink` is total over the schema: an address the schema does not have fails
the render, a disabled card `$body` and a roster member's `title` included, so
read a title as `if row.held and "title" in row.value { qm.ink(row.value,
"title") } else { row.title }`, an unheld row's `value` being `none`. Blank
content, a blank date, a typed dictionary and a matrix give `none`, and a
display pattern on an address that is not a date's fails the render.

A downstream quiver migrates each plate in four steps:

1. The import line becomes `#import "@local/quillmark-helper:0.2.0" as qm`.
2. `ink(x).f` becomes `qm.ink(x, "f")`, `display(..)` becomes `qm.ink(..)`,
   and `field-region` becomes `qm.region`.
3. `data` becomes `qm.data`, and every other helper name takes the `qm.` prefix.
4. A bare print of a `data` value that should stay clickable,
   `#data.subject`, becomes `#qm.ink(qm.data, "subject")`.

## A declined construct warns under one code

**`quill.validate(doc)` warns `backend::declined_construct`, the render's own
diagnostic, where it warned `validation::declined_construct`; that code is
gone.** The two lists are equal, message, hint and `args` included, so a host
that routed the validate code apart from the render's routes one code. A host
collecting validate's own findings by the `validation::` prefix no longer
collects the declines.

`validate` reads the plate a render compiles, so a document that does not
compile, one holding a value its field's type refuses, draws no decline until
it compiles; 0.124 read the authored values instead.

A render's declines stand after its backend's other warnings, after
`typst::unregistered_element` under Typst, where they stood before it.

## A typed set reports what its markdown drops

**`writer.set` and `setAll` in WASM, `set` and `set_all` in Python and
`TypedWriter::set` / `set_all` in Rust return a `parse::dropped_construct`
per construct a `richtext` markdown string drops, at the string's path, such
as `main.subject` or `main.tags[0]`, where the drop was silent.** `addCard`
returns its fields' warnings ahead of its body's. A string the render floor
wraps into an array, a bare string on an array of `richtext`, reports at
`[0]`, from a set, a conform and `validate` alike, and a conform reports a
string in a variant cell the discriminant does not select.

## A table knob outside its set rests as written

**A stored table's `align`, `widths` or `headless` holding a value outside
its set stays as written and reads as absent, where normalization removed
it.** `align: "middle"`, `headless: "true"` and `"align": null` render as the
quill's default, as before, but now ride the stored bytes, so the content
hashes over them. A cell's `align` and `valign` already rode this way. Write
`null` nowhere a key means its default; leave the key out.

## A whole-document revise names each dropped anchor with its line

**`writer.reviseDocument`'s `droppedAnchors` holds `DocumentAnchor`s, `{ id,
path, line }`, the shape `doc.toAnnotatedMarkdown()` lists, where an entry
held `path` and `id`.** A card's anchors list fields first, then its body,
and an anchor is matched at its exact address, so one dropped from
`items[1]` is named though `items[2]` holds the same id.

## Markdown

**A line opening with three or more backticks whose info string holds a
backtick opens no code fence, as CommonMark reads it, so a `~~~` card block
under it opens its card.** 0.124's card scanner read such a line as a fence
and kept the cards below it in the body.

**A raw tag inside a footnote definition no longer warns on its own:** the
definition's one `footnote` warning covers everything in it.

## A placed table aligns its cells as an unplaced one does

**A table placed by `<qm-table align=…>` aligns its cells as it would
unplaced under the plate's `#set table(align: …)` and a vertical
`#show table.cell: set align(…)`.** 0.124 gave a cell the placement's
horizontal alignment under a vertical `table.align` such as `horizon`, and
`top` under a vertical `table.cell` rule. A horizontal alignment set by a
`table.cell` show rule still yields to the alignment around a placed table, as
in 0.124; set it by `#set table(align: …)` instead.
