# 0.128 → 0.129 — an object alone in a legacy group is no longer written `flat`, and `ui.layout: flat` is deprecated

**`schema()` no longer writes `ui.layout: flat` on an object alone in its
legacy `ui.group`.** Nothing reports the change. An editor that read the flag
to let the group header name that object finds it absent: detect the case
itself, a group whose only field is an `object`.

**`ui.layout: flat` warns `quill::deprecated_flat`, one per field, naming its
path.** It still loads where it loaded, and `schema()` still echoes it. No
editor honors it: a card's top-level `object` is a panel framing its
properties, and a nested one a subform. Drop the key.

**A card-level field outside every group, declared after a top-level `object`
or a grouped field, warns `quill::field_after_object`.** An editor draws it
above the groups. Declare it ahead of them, or move it into an object.

| Break | Surface | Action |
|---|---|---|
| An object alone in a legacy `ui.group` carries no `ui.layout: flat` | `schema()` | Detect a group whose only field is an `object` directly |
| `ui.layout: flat` warns `quill::deprecated_flat` | `Quill::warnings`, every render's warnings, `quillmark validate` | Drop the key |
| A loose field after a top-level object or a grouped field warns `quill::field_after_object` | `Quill::warnings`, every render's warnings, `quillmark validate` | Declare it ahead of the groups, or move it into an object |
