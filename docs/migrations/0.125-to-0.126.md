a vendored package loads every face it holds, where the backend skipped it.** A
plate naming a collection's family renders in it, where it rendered in a
fallback face and warned `unknown font family`. A quill whose only fonts are
collections renders in them, where it rendered in the embedded Roboto, so a
plate there naming `Roboto` warns `unknown font family`.
