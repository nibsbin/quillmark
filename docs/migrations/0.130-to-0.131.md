# 0.130 → 0.131 — font family and size in richtext, and a host font library

A writer sets a run of richtext in a font family or one size step up or down,
spelled in markdown as a `qm-font` pair, and an app hands the engine a font
library of its own to choose families from. The first two sections are the
changes no type checker reports; the table closing the guide lists every
break.

## Stored rows

**The storage tag is `quillmark/document@0.131.0`**, the first that can hold a
`font_family` or `font_size` mark. A row under `@0.129.0` or `@0.124.0` loads
as before, and a save rewrites it under the new tag, so a hash over stored
bytes recomputes once, though nothing else in the row moves. A 0.130 build
refuses a row from then on, as a build too old for its tag, so deploy every
reader before any writer.

## Markdown

**`<qm-font family="Carlito" size="large">text</qm-font>` inside a line sets
its text's family and size, where 0.130 dropped the tags and warned
`parse::dropped_construct` (`qm-font`).** Markdown that spelled one now
imports with font marks and renders in that family and size. `size` is
`small` or `large`; `normal` holds the surrounding size inside a sized pair.
An attribute other than `family` and `size`, or a size outside the three,
drops alone and warns `qm-font[<name>]`. A tag setting nothing, or a pair
left open, drops and warns `qm-font` as before. A pair of `qm-font` tag lines
around blocks is still an element named `font`.

[Markdown Syntax](../authoring/markdown-syntax.md#font-family-and-size) has
the full rules.

## Rendering

A Typst render sets a font run's family ahead of the font list in force, so a
character the family lacks falls through to the surrounding font. A family no
loaded font holds keeps the surrounding font and warns
`typst::unknown_font_family` once per family and field, at the field's path.
The size steps are the helper's `qm.font-steps`, `(small: 0.85em, large:
1.2em)`, which a plate sets with `#qm.font-steps.update(..)`. Code spans and
equations keep their own font and size. An acroform render ignores both marks.

An app adds fonts through the engine: `Engine::with_fonts(files)`, the
`fonts` option of `new Engine(..)` in JavaScript, `Engine(fonts=..)` in
Python, and `--font` on `quillmark render` and `quillmark workspace`. A family
the quill ships hides every face of that family in the library, and the
embedded Roboto loads only for a quill shipping no fonts and holding no
Roboto in the library. A file other than `.ttf`, `.otf`, `.ttc` or `.otc`
fails the engine with `engine::font_unsupported`, and one holding no face
Typst reads with `engine::font_unreadable`. `engine.fontFaces(quill)` lists
the faces a session of the quill sets type in, with their bytes.

## Every break

| Break | Surface | Action |
|---|---|---|
| A save writes `quillmark/document@0.131.0`, and a 0.130 build refuses the row from then on | stored documents | Ship readers before writers; a hash over stored bytes recomputes |
| An inline `qm-font` pair imports as `font_family` and `font_size` marks, where it dropped and warned `qm-font` | imported content, rendered output, `Parsed.warnings` | None |
| `parse::dropped_construct` names `qm-font[<attr>]` for an attribute a `qm-font` pair cannot read | `Parsed.warnings`, `doc.warnings`, revise warnings | Drop the attribute, or let the warning stand |
| A font run in a family no session font holds warns `typst::unknown_font_family` | Typst session warnings, `RenderResult.warnings` | Supply the family, or treat the code as an error where a hard failure is wanted |
| `MarkKind` gains `FontFamily { name }` and `FontSize { step }`, with `FontStep`; `StoredDocument` gains `V0_131_0`, and `STORAGE_V0_131_0` is the current tag | Rust | An exhaustive `match` adds the arms |
| `ContentMark` gains `font_family` and `font_size` members | WASM | A `switch` over `type` handles them |
| `TypstBackend` is a struct holding a font library: the unit value `TypstBackend` is `TypstBackend::default()`, or `TypstBackend::new(Arc<FontLibrary>)` | Rust | Construct it |
| `quillmark_typst::workspace::workspace` takes a `&FontLibrary` third | Rust | Pass `&FontLibrary::default()` for no library |
| A refused font in `new Engine({ fonts })` rejects the engine's first verb | WASM | Catch the rejection |
| `quillmark workspace --font` writes `fonts/host-<n>.<ext>` beside the quill's fonts | CLI | None |
