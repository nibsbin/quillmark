# Migration Guides

A release that breaks the document syntax, the plate-JSON wire format, or a
public API ships a guide for that version step. Most breaks are hard cutovers —
the old form stops parsing or compiling — so the guide is the path forward, not
an optional read.

Each guide covers one step. To cross several versions, work through them in
order; each states its own breaks in full. The rows below name the step's
headline break, enough to pick the guide.

No step requires migrating a stored document: the storage DTO's bytes and tag
hold across every step here except 0.111 → 0.112, 0.114 → 0.115,
0.115 → 0.116 and 0.123 → 0.124, where canonical bytes move (content hashes
recompute) and the tag becomes `quillmark/document@0.112.0`, `@0.115.0`,
`@0.116.0` and `@0.124.0` in turn,
and 0.122 → 0.123, where a row holding a comment that ends in whitespace loads
without it and rewrites once when saved, under the same tag. A build older
than a step that moves the tag refuses a row the newer build has rewritten.

## Guides

| Step | What changes |
|---|---|
| [0.124 → 0.125](0.124-to-0.125.md) | `Quill::validate` warns `backend::declined_construct`, the render's own diagnostic, where it warned `validation::declined_construct`, and draws none for a document the render floor refuses. A typed `set` / `setAll` returns the `parse::dropped_construct` of each `richtext` string it writes, and `addCard` its fields' ahead of its body's. A table `align`, `widths` or `headless` outside its set rests as written and reads as absent, where normalization removed it. `droppedAnchors` holds `DocumentAnchor`s with their `line`, matched at the exact address. A backtick fence opener whose info string holds a backtick opens no fence for the card scanner, and a raw tag inside a footnote definition warns nothing beside the `footnote`. A placed table aligns its cells as an unplaced one does. `ImportWarning` is a struct, `Container::Element` holds a `carrier::Element`, the typed writer's `set` / `set_all` return `Vec<Diagnostic>`, and `SessionHandle::update` takes the session's `QuillConfig`. |
| [0.123 → 0.124](0.123-to-0.124.md) | An HTML block drops as CommonMark reads it, now with a warning, and a line holding only element and `qm-table` tags reads as a tag line wherever it stands. A fenced block holding `<!-- a --> b` keeps its line, text after a block nested in a tight list item opens its own line, and a line holding only tags on the line after a table's rows ends the table. `- [ ]` and `- [x]` render a box, ticked for `[x]`, and a footnote definition drops with a warning, where it silently defined a link. A raw tag a markdown import drops warns `parse::dropped_construct` at its body, on `doc.warnings`, and `quillmark validate` fails an `example.md` holding one; a one-shot render's `RenderResult.warnings` no longer carries `doc.warnings`, and in WASM a JSON `null` inside a returned value crosses as `null`, where it crossed as `undefined`. A `</u>` closes the innermost open `<u>` across `**`, an unclosed `<u>` drops where its text ends, and export writes `<u>` outside the delimiters. `from_markdown` returns `Imported { content, warnings }`. A revise returns `Revised { delta, warnings }`, where it returned the `Delta`, and `add_card` its body's warnings; WASM `importMarkdown` returns `{ content, warnings }`, and Python's `revise_body` / `revise_field` / `add_card` return the warnings. `Quill::validate` warns `validation::declined_construct` at a field holding a construct the backend declines, an image under Typst, and an acroform render warns `backend::declined_construct` for every construct but the paragraph. A `qm-table` wrapper lays out its table, a `qm-*` element is stored content rendered through the plate's `elements` registry, and a save writes the storage tag `quillmark/document@0.124.0`. A revise keeps the id of each island it leaves unchanged or edits in place. Text after a card-yaml block's root value, and a mapping holding two keys of one text such as `1` and `"1"`, fail the parse where they dropped. `quillmark validate` reports a bad `typst.plate_file` under the render's `typst::plate_*` codes, where it raised `cli::plate_file_*`. A base PDF with hybrid cross-reference data fails as `pdf::xref_stream`. A WASM options object, `Addr` or `CardInput` inheriting an unknown key from a null-prototype object throws. |
| [0.123.0 → 0.123.1](0.123.0-to-0.123.1.md) | A `richtext(inline)` value holding an inline `<br>` fails as `validation::not_inline`, where 0.123.0 glued the words either side of it into one line. An inline `<br>` renders as a line break in a paragraph and a table cell, and a space in a heading, where it rendered nothing, and nothing reports the change. A `\n` in a table cell's `text` is a line break, where normalization made it a space. A `<br>` in an image's alt is a space. |
| [0.122 → 0.123](0.122-to-0.123.md) | A number under a `boolean` field, a matrix member's bare tick included, renders by whether it is non-zero. A float of magnitude at most `2.220446049250313e-16`, such as `1e-17`, renders `true` where it rendered `false`, and nothing reports the change. An acroform `form.pdf` whose page `/Annots` hold a widget annotation fails to open as `pdf::existing_acroform`, whatever its catalog `/AcroForm` holds. One whose trailer, catalog, page-tree node or `/Info` object names a key twice or with no value, or holds a token where a key belongs, fails to open as `pdf::parse`, or `pdf::write` for `/Info`. A YAML comment drops the whitespace ending its line, a stored row's included, so `to_markdown` writes `# note` for `# note  `, and nothing reports the change. A comment under a tagged empty value, inside an alias key's value or around a merge keeps the slot the YAML gives it, where it moved or dropped, and nothing reports the change; a top-level alias key keeps its place in the field order, where it moved to the block's end. A WASM options object, `Addr` or `CardInput` that is not a plain object throws, a class instance or `Object.create(defaults)` included, where 0.122 read its keys, own or inherited; so does a non-enumerable key its verb does not read. An open matrix's added item whose `title` is `""` or whitespace alone fails as `validation::enum_violation`, where it printed a bare tick. |
| [0.121 → 0.122](0.121-to-0.122.md) | Only `true` and `false` are booleans: an unquoted `y`, `n`, `yes`, `no`, `on` or `off`, in any case, is the text written. A `string` field that printed `false` for `middle_initial: N` prints `N`, and nothing reports the change. A word under a `boolean`, `number` or `integer` field, a matrix member's tick included, fails as `validation::type_mismatch`. In `Quill.yaml` a word where a boolean belongs fails to load, and `values: [US, NO, DE]` loads. Every stamped checkbox, checked or not, carries `/AP << /N << /Yes … /Off … >> >>` with `/AS` naming its state, so a filler can toggle it, where a checked box carried one stream and an unchecked box no `/AP`. A reader taking `/N` only as a stream draws an empty box, and nothing reports it. `StampOptions` gains `states`; `AppearanceStates::Selected` stamps the one-stream shape for such a rasterizer. A Typst quill whose `plate_file` names a file at a path Typst refuses, such as a name holding a `\`, fails to open as `typst::plate_path_invalid`, where it loaded that plate as `main.typ` and so shadowed the quill's own `main.typ`. A WASM options object refuses a key it does not read: `engine.render` and `session.render` throw on a render option outside `format`, `ppi`, `pages` and `regions`, and `new Engine` on a key other than `backends`, where each dropped it. `engine.render(quill, doc, { today })` rejects rather than rendering the local date; the date is the trailing argument. A comment keeps the slot the YAML gives it: one in a sequence at its key's column, indented less than its block, in a compact nested sequence or trailing a plain scalar's continuation line re-emits there, where it moved or dropped, and nothing reports the change. `parse::unsupported_yaml_tag` warns on every tagged node at its own path, a flow collection's and a sequence element's included. A column-zero key outside the field grammar fails as `parse::invalid_structure`. A failed Typst compile's error carries the quill's load warnings after its errors, and nothing reports the change: a host counting every diagnostic as an error reads `severity`. |
| [0.120 → 0.121](0.120-to-0.121.md) | A matrix member is held by being present, so a mapping naming no `held` flips from unticked to ticked with nothing reporting it, and a mapping storing `held` — as 0.120's strict write and the editor stored every tick — fails validation as `validation::held_stored`. A matrix reaches the plate as the members it holds, so a plate reading `held` or a member's `title` fails to compile and prints through `roster` instead, and a member's tick is its own address. An open matrix admits items a document adds. |
| [0.119 → 0.120](0.119-to-0.120.md) | `quill::table_column_not_flat` is `quill::table_column_not_leaf`: the refusal of a `ui.layout: table` column that is not a leaf is unchanged but for its code. |
| [0.117 → 0.118](0.117-to-0.118.md) | A card kind declares `seed:`, which Add Card writes into a new card of the kind. A document's `$seed` warns wherever the card it seeds would: an undeclared nested key (`validation::unknown_field`), a stranded variant cell (`validation::out_of_variant`), a `$body` that is not importable markdown (`validation::seed_overlay_shape`) and an array past `max:` (`validation::cardinality`), so `quillmark validate` can fail a quill whose `example.md` carries one. `CardSchema` has a public `seed` field. |
| [0.116 → 0.117](0.116-to-0.117.md) | `example:` and `body.example` leave the quill schema: a `Quill.yaml` declaring either, at any depth, fails to load (`quill::field_parse_error`, `quill::invalid_body`), and a format hint moves into `description`. The `quill::example_{type_mismatch,not_in_enum,format_violation,on_namespace,over_max}` and `quill::body_example_*` codes are deleted and `richtext_example_import` is `richtext_default_import`; `quill::example_reference` is new, for the example document. The blueprint drops its `# e.g.` and `# body e.g.` lines but a matrix's member hint, and `schema()` carries no `example`, so `QuillFieldSchema.example` and `QuillCardBody.example` are deleted. Also: `$quill: name@latest` fails as `parse::invalid_quill_reference`; write the bare `name`, which matches the same versions. `VersionSelector::Latest` is `Any` and has no `Display`, and `QuillReference::latest` is deleted. `version: ""`, a tagged version such as `!!float 1.10`, and a card kind named `main` fail to load. `quillmark validate` reads a root `example.md` as the quill's example, and fails the quill on any diagnostic it carries. A quill shipping no fonts renders in the embedded Roboto, not Figtree. |
| [0.115 → 0.116](0.115-to-0.116.md) | `!must_fill` is removed, with its store and fill APIs. A card of an undeclared `$kind`, and a body under `body.enabled: false`, render and warn where they failed, on a one-shot render's `warnings` and from `quill.validate(doc)`; an undeclared key warns too. A typed dictionary or table row carries `$ink` and `$path`. A card with no `$kind`, and a non-mapping payload, fail at the fence. Also: the Rust render verbs take a required `today: CalendarDate`, WASM `paint` takes one scale, a card-wire item refuses `fill` or any unknown key, the blueprint leaves every body empty with its `body.example` on a `# body e.g.` line, `FORMAT_RULES` is `MARKDOWN_RULES`, and `blueprint_instruction` is deleted. |
| [0.114 → 0.115](0.114-to-0.115.md) | A `matrix` member mapping takes the ordinary ladder: a mapping naming no `held` is unheld, where presence alone ticked it, so `{ detail: X }` means what `{ held: false, detail: X }` means. It is the release's one silent break — the value is well-typed under both readings, and the page prints the box unticked and the member's columns blank — so documents storing a ticked member as a bare mapping need `held: true` spelled before upgrading. Two copies of a fact an island already carried go. An island’s canonical form loses `loss`, and a block island’s line is a `para` — whether its slot’s markup is a block is read off the island’s `type`, where the mint and both emitters already read it. A host branching on `line.kind === 'island'` reads the island instead, and the `setKind` in every block-island bundle goes. `ContentIsland.loss`, `ContentLossClass`, `Loss`, `Island::with_loss`, `IslandType::default_loss` and `LineKind::Island` are deleted, and the closed content vocabularies drop to four. Canonical bytes move for every document holding an island, so content hashes recompute and the tag becomes `quillmark/document@0.115.0`. Stored rows keep loading: the decoder reads `island` as `para`, and ignores a `loss`, permanently. Also: a schema is loaded, not deserialized — `QuillConfig`, `CardSchema` and `FieldSchema` drop `Deserialize` and `FieldSchema::from_quill_value` turns crate-internal. All three still serialize. A matrix roster is one flat mapping of `id: Title`, so `MatrixGroup`, `MATRIX_GROUP_KEY`, `QuillMatrixGroup`, the `group` key on every projected member and `quill::duplicate_matrix_member` all go. A blueprint stops *naming* a variant-bearing enum's dormant worlds: each is its own cells, commented out under a `# when <MEMBER>:` header. `quillmark validate` compiles the plate: it renders the empty document, the blueprint and the seed through the quill's backend, so a quill whose plate does not render exits `1` where it exited `0` — `--no-render` is the configuration read on its own. And a `ui.layout: table` column that is not a leaf is `quill::table_column_not_flat` at load. |
| [0.112 → 0.113](0.112-to-0.113.md) | The `pdfform` backend becomes `acroform` at every layer — crate, `backend:` id, feature, `pdfform::*` codes — with no alias, so every form quill's `Quill.yaml` stops rendering until edited. The content vocabularies close: a line `kind`, container, mark `type`, island `type` or `loss` outside the built-ins stops opening a stored row. Every column-zero `~~~` block is a card whatever its info string, so a `~~~rust` fence in a body opens one where it opened a code block — a backtick fence is the escape hatch. A content line op the text or block contradicts lands and the terminal normalize settles it, so `Ok` stops meaning the op landed as written. A `Content` read omits a zero `Container.instance` where it spelled one on every container, so the key a host read off a read is absent and `instance` is optional in TypeScript. Every `quillmark-content` and `quillmark-core` item is named at the module that defines it, so a Rust consumer's `quillmark_content::Delta` and `quillmark_core::Document` imports gain a module segment — the `quillmark` facade absorbs it and moves nothing. Also `reader.get` in the values form, `reader.resolve()`, the `toStored` / `fromStored` / `loadStored` renames, a wide pruning sweep, and a group of tightened refusals no type checker reports: new `parse::*` and `backend::*` codes, a field write past the §8 field count refused at the write, a `Quill.yaml` declaring more fields than one card carries refused at load, a stricter `main:` and `Quill::validate`, and the `acroform` canvas-box origin. |
| [0.111 → 0.112](0.111-to-0.112.md) | One spelling per name: every vocabulary member carries its payload in `attrs`, built-ins included, so a host reading `line.level` or `mark.url` reads them under `attrs` and the authored lane refuses the old spelling. |
| [0.110 → 0.111](0.110-to-0.111.md) | A fix release: four surfaces refuse input they were producing something wrong from. The one break that can stop a render is a pdfform background carrying its own `/AcroForm` (`pdf::existing_acroform`). |
| [0.109 → 0.110](0.109-to-0.110.md) | Every hand-built container literal must spell `instance`: the discriminator becomes a required field on the whole-document write lanes, and `ContentContainerInput` is deleted. |
| [0.108 → 0.109](0.108-to-0.109.md) | Canonical form becomes a type — `Normalized`, which every codec returns and every projection takes — and `Container` gains `instance`, so an exhaustive `match` needs `..`. |
| [0.107 → 0.108](0.107-to-0.108.md) | A cell holds a value, a namespace holds cells: a `default:` / `example:` on a typed dictionary fails load, an absent container reaches its properties' defaults (a render-output change), and `must_fill:` retires. |
| [0.106 → 0.107](0.106-to-0.107.md) | A declared type means the same thing at every depth. The break no checker reports: a plate read of a typed-table row cell regions on the cell (`main.refs[0].org`). A `date` lowers to a native `datetime`. |
| [0.105 → 0.106](0.105-to-0.106.md) | A schema address may step one property into a declared container — so region addresses shift — and an `enum` may declare `variants:`, which rests that field as `{value: <member>, …}` rather than a bare string. |
| [0.104 → 0.105](0.104-to-0.105.md) | A field's blank becomes a property of the field rather than a member of its type's domain: an absent no-`default:` enum renders blank instead of `values.first()`, and every enum accepts `""` as input. |
| [0.103 → 0.104](0.103-to-0.104.md) | `type: enum` with `values:` is the one spelling of a closed string domain (`enum:` is a load error), and a geometry address spells an array element bracketed: `main.references[0]`. |
| [0.102 → 0.103](0.102-to-0.103.md) | WASM: `init()` resolves to the core surface, and `Quill`, `Document` and the free functions leave the static exports — destructure them from `await init()`. CLI: `render --verbose` writes its progress to stderr. |
| [0.101 → 0.102](0.101-to-0.102.md) | The pre-1.0 vocabulary reset: `install*` → `overwrite*`, `setBody` → `reviseBody`, `LiveSession.apply` → `update`, and the `edit::*` codes rename. `@quillmark/wasm` ships `--target web`, so `await init()` is required. |
| [0.100 → 0.101](0.100-to-0.101.md) | Two Rust constructors leave the published surface (`Document::from_main_and_cards`, `QuillConfig::from_yaml`), and the change-bundle verbs take one `ChangeBundle` struct, which gains an island channel. |
