# Migration Guides

A release that breaks the document syntax, the plate-JSON wire format, or a
public API ships a guide for that version step. Most breaks are hard cutovers —
the old form stops parsing or compiling — so the guide is the path forward, not
an optional read.

Each guide covers one step. To cross several versions, work through them in
order; each states its own breaks in full. One span guide sits above them:
[0.92 → 0.102](0.92-to-0.102.md) routes a consumer across that range and leads
with the two breaks a type checker does not report.

!!! note "0.93 was never separately published"

    The 0.93 milestone folded into 0.94.0 — no 0.93.x release was tagged.
    Upgrading from 0.92.1 means following **0.92 → 0.93** and **0.93 → 0.94**
    in sequence.

## Guides

| Step | What changes |
|---|---|
| [0.106 → 0.107](0.106-to-0.107.md) | A declared type means the same thing at every depth: every type nests at every position the schema admits, lowering dispatches on the schema node beside each value rather than on tables of top-level names, and one address tree answers what a plate may address on either backend. Lead with the break no type checker reports: **a plate read of a typed-table row cell regions on the cell**, so `#data.refs.at(0).org` regions as `main.refs[0].org` where it regioned as `main.refs` — a wrong address, not a missing one, routing a click on one cell to the whole table. Two schema literals that loaded before now fail **load**: a nested `richtext(inline)` `default:` / `example:` over one paragraph (`validation::not_inline`), and a container-shaped literal on a variant-bearing enum (`quill::default_type_mismatch`). A `date` lowers to a **native** `datetime` — `.value` and the paren `display` form are hard compile errors — and `display(field, ..)` places its clickable ink by schema address instead. A nested `date` / `richtext` / `plaintext` reaches the plate as its declared type where it arrived as a bare string or as internal canonical-content JSON. `plaintext(field)` is removed, having never acquired a caller. Widenings: containers nest freely (`quill::nested_object_not_supported` and `quill::nested_array_not_supported` are gone), a variant cell carries any type (`quill::variant_field_type` is gone), a row property is a writable address on either backend, `blueprint()` expands a container at every depth, a `default:` reaches the plate from every position it can be declared in, a single-assignment `let` alias keeps its address, and `VARIANT_DISCRIMINANT_KEY` joins the WASM runtime exports. Stored blobs and the document syntax are untouched. |
| [0.105 → 0.106](0.105-to-0.106.md) | A schema address may step one property into a declared container, and an `enum` may declare `variants:` — a per-member field set that exists only in the world where the discriminant holds that member. Lead with the break no type checker reports: **region addresses shift**, so a plate reading `#data.classification.poc` regions as `main.classification.poc` where it regioned as `main.classification`. The step is gated twice — a property the container *declares*, read directly off `data` — and `doc.pathFor` mints the address a consumer would otherwise spell by hand. `variants:` is the one key that changes a field's resting shape, from a bare string to `{value: <member>, …that member's fields}`, so a plate reads `data.<field>.value` for the discriminant and every cell of the live world unguarded inside the `values ∪ blank` branch it already owes. `usaf_memo`'s four `cui_*` fields move under `classification`'s `CUI` variant, a break that fails quietly: the stale keys draw no diagnostic and simply stop being read. `EditError::UnknownField` becomes a struct variant carrying the in-field path, and an undeclared property anchors at `main.address.zip` rather than at the field. Additive: `field-region(field, body)`, `font` / `size` / `align` on `form-field`, `FieldSchema::variants` and `variant_field`, `VariantFields` and `VARIANT_DISCRIMINANT_KEY`. Stored blobs are untouched, and a quill declaring no variants projects identically at every surface. |
| [0.104 → 0.105](0.104-to-0.105.md) | A field's blank becomes a property of the field rather than a member of its type's domain. An `enum`'s blank is `""`, reserved and outside `values:`, so an absent no-`default:` enum renders blank instead of borrowing `values.first()` — a choice nobody made, previously reachable from a cosmetic `values:` reorder. The accepted domain widens to `values ∪ blank` for **every** enum, not only defaultless ones, so an authored `""` now clears the gate and reaches the plate: a plate branching with `else` silently renders a variant nobody chose, and `data.at(key, default: X)` is not a guard because every declared key is always present at render. `date` / `datetime` coercion stops mapping `""` to null, so a blank date outranks a `default:` exactly as `""` already did for `string`. Declaring `""` in `values:` is a load error (`quill::enum_blank_member`) while `default: ""` stays valid and unchanged. `zero_value` → `blank`, `FieldSource::Zero` → `Blank`, and the wire token `"zero"` → `"blank"`. Separately, obligation leaves `default:` for its own `must_fill:` key, deriving `default.is_none()` so no quill needs editing, and `Quill::validate` gains a schema-side trigger that warns on a cell the schema obliges and the document never authored — so a merely incomplete document no longer validates clean, and a consumer reading "any diagnostic means not done" changes verdict on documents that did not change. Authoring the blank discharges the obligation where `null` does not, the one place `null ≡ absent` stops carrying. Additive: `must_fill:`, `ui.blank_title`, `quillmark:must_fill` and `quillmark:blank_title`. Stored documents are untouched. |
| [0.103 → 0.104](0.103-to-0.104.md) | The `enum:` modifier on `type: string` retires: `type: enum` with a `values:` list is the one spelling of a closed string domain, and `enum:` on any type is a load error whose message names the replacement. `QuillConfig::schema()` re-emits every domain as `values:` (the WASM `QuillFieldSchema.enum` field is gone), and the transform schema now carries a domain it was silently dropping, so a generated validator rejects out-of-domain values it used to accept. Separately, geometry addresses parse segment-wise: `RenderedRegion.field` / `FieldRegion.field` / `ContentHit.field` spell an array element bracketed (`main.references[0]`), the spelling `Diagnostic.path` already uses — and `locate` / `fieldBoxes` answer for a deeper-than-one-segment address for the first time, which was dead for every `array<richtext>` element and every nested pdfform key. `to_markdown` writes `***` for a thematic break, so a rule as a bullet item's first block survives the round-trip instead of losing its item. `@quillmark/wasm` moves its `engines` floor to Node 24. Additive: `doc.pathFor` / `doc.cardPath`, and a quill declaring the block constructs its plate does not typeset, which raises the new `plate::unsupported_construct` family. Stored blobs and rendered output are untouched. |
| [0.102 → 0.103](0.102-to-0.103.md) | WASM: `init()` resolves to the core surface instead of `void`, and `Quill`, `Document` and the free functions leave the static exports: destructure them from `await init()`. The gate becomes the only way to obtain one, so the pre-init mistake stops being expressible and `runtime::not_initialized` retires with the door it guarded. `Engine`, `MAIN_CARD_ADDR`, `isQuillmarkError` and the open-set guards are unchanged, as are the `Quill` / `Document` **type** exports. CLI: `quillmark render --verbose` writes its progress lines to stderr, so `--stdout` no longer frames the artifact with them. Documents, stored blobs, and the Rust and Python libraries are untouched. |
| [0.92 → 0.102](0.92-to-0.102.md) | **Span guide.** The ten steps in one page, leading with the two breaks a type checker does not report: `await init()` and the `insertCard(card, at?)` reorder. The other twenty are a table, each row pointing at the step that owns it. |
| [0.101 → 0.102](0.101-to-0.102.md) | The pre-1.0 vocabulary reset. `install*` → `overwrite*`, writer `setBody` → `reviseBody` (now returning the receipt), `LiveSession.apply` → `update`, `getMarkdown` / reader `getBody` → `bodyMarkdown`, `store/removeSeedNamespace` → `*SeedOverlay`, `schemaVersionOf` → `storageVersionOf`. The `edit::*` codes for content-field failures rename and gain a `codec` arg, so one code covers both codecs; `richtext::not_inline` becomes `validation::not_inline`. Documents and stored blobs are unaffected. Separately, island-id minting splits by case: restoring a deleted island re-lands the id it was deleted under, and the island channel states two contracts it previously left to the implementation. `@quillmark/wasm` ships `--target web`: `await init()` is required before first use, and the bundler plugins the package used to demand are gone. |
| [0.100 → 0.101](0.100-to-0.101.md) | Two Rust constructors leave the published surface: `Document::from_main_and_cards` becomes crate-internal (its invariants were `debug_assert`s feeding a release-build panic), and `QuillConfig::from_yaml` is removed for `from_yaml_with_warnings`, which keeps the structured diagnostics the boxed string destroyed. The change-bundle verbs take one `ChangeBundle` struct in place of three positional op arguments, because the bundle gains an island channel: `IslandOp` edits an island's payload or inserts one with its slot, so a table or image edit keeps the field's identity anchors instead of falling back to a whole-field `install`. On the bindings the channel is additive (`applyChange`'s new optional `islandOps`); documents and stored blobs are unaffected. |
| [0.99 → 0.100](0.99-to-0.100.md) | Card `$id` is removed: the reserved key, `find_card` / `set_card_id` / `remove_card_id`, the collision errors, and `cardIndexById` / `card_index_by_id` plus the projected `id` on both bindings. Per-card consumer keys move to `$ext` under a namespace you own, with no uniqueness guarantee. `Content`, `Line`, `Mark`, and `Island` take `#[non_exhaustive]`, the four the 0.99 sweep missed, so their literals give way to `new` plus `with_*` setters. A string-valued `plaintext` field reads through the literal codec instead of markdown, and `reader.getContent` returns a content field's corpus whichever lane built the document. Load conforms content fields to one resting form per codec (`Quill::parse` / `Quill::conform`, the bound door), and `Diagnostic.args` carries the facts a message interpolates. |
| [0.98 → 0.99](0.98-to-0.99.md) | The Rust API opens ahead of 1.0.0: `#[non_exhaustive]` across the published crates, so an exhaustive `match` needs a `_` arm and a struct literal gives way to `new` plus `with_*` setters. `attrs` beside a built-in discriminator is rejected where a host authors it, instead of resolving to the built-in and dropping the payload in silence. Island `loss` opens; a handle from a second copy of `@quillmark/wasm` is refused. |
| [0.97 → 0.98](0.97-to-0.98.md) | The block vocabulary opens — an unrecognized line kind or container round-trips opaque instead of failing the load. `OutputFormat::Txt` retires on every surface. |
| [0.96 → 0.97](0.96-to-0.97.md) | The WASM transport read renames to `Document.getStored`. A card `$id` becomes unique per document and never empty. |
| [0.95 → 0.96](0.95-to-0.96.md) | One address grammar (`DocPath`) on every boundary; mutator failures gain namespaced `edit::*` codes; `view()` renames to `reader()`. |
| [0.94 → 0.95](0.94-to-0.95.md) | One insertion verb (`insertCard(card, at?)`) and one parse entry (`Document::parse`); the typed writer becomes the one schema-bound door; `datetime` splits into strict `date` and `datetime`. The split carries a **corpus precondition**, not just a schema edit: the two grammars are disjoint, so a stored value outside the type you rename to strands at render. Audit the deployed rows before publishing the rename. |
| [0.93 → 0.94](0.93-to-0.94.md) | `type: richtext(inline)` retires for `inline: true`; typed field writes land; `ui.order` is removed — declaration order is the ordering contract. |
| [0.92 → 0.93](0.92-to-0.93.md) | The blueprint placeholder splits into value and marker axes: the `!must_fill` tag replaces the `<must-fill>` string sentinel, and a bare null falls back to default/zero. |
| [0.91 → 0.92](0.91-to-0.92.md) | `!fill` renames to `!must_fill` with no alias — a stale `!fill` silently loses placeholder status. `$seed` carries per-card-kind seed overlays. |
| [0.90 → 0.91](0.90-to-0.91.md) | A card-yaml closing `~~~` must sit at column zero. Data-field names and the 100-level nesting limit are enforced on every input path. |
| [0.89 → 0.90](0.89-to-0.90.md) | `Quill` becomes engine-free data — the engine takes the quill per call. The WASM package collapses to a single `@quillmark/wasm` root import. |
| [0.88 → 0.89](0.88-to-0.89.md) | A `$quill` name or version mismatch fails the render instead of warning. |
| [0.87 → 0.88](0.87-to-0.88.md) | The schema-aware form view gives way to `quill.validate(doc)`; one `Card` shape flows both in and out. |
| [0.86 → 0.87](0.86-to-0.87.md) | Array fields require an `items` element schema; `type: date` folds into a unified `type: datetime`. |
| [0.85 → 0.86](0.85-to-0.86.md) | A partial document renders without error; the canonical card-yaml fence becomes a bare `~~~`. |
| [0.83 → 0.84](0.83-to-0.84.md) | The Must Fill / Endorsed schema model replaces `required:`. |
| [0.82 → 0.83](0.82-to-0.83.md) | The `$`-prefixed plate JSON wire format retires the legacy uppercase reserved keys. |
| [0.81 → 0.82](0.81-to-0.82.md) | card-yaml metadata replaces the `---` / `QUILL:` frontmatter and fenced cards. |
| [`@quillmark/wasm` 0.77 → 0.80](wasm-0.77-to-0.80.md) | WASM consumers crossing the card-syntax release. |
