# Migration Guides

A release that breaks the document syntax, the plate-JSON wire format, or a
public API ships a guide for that version step. Most breaks are hard cutovers —
the old form stops parsing or compiling — so the guide is the path forward, not
an optional read.

Each guide covers one step. To cross several versions, work through them in
order; each states its own breaks in full.

## Guides

| Step | What changes |
|---|---|
| [0.112 → 0.113](0.112-to-0.113.md) | The values form lands (`reader.values()` / `writer.setValues`, and per card `reader.card(i).values()` / `writer.card(i).setValues`): a document as plain values, content leaves as their codec's text at every depth, everything else as stored, sparse and total, an absent input axis untouched and a present one replaced, an unedited write-back a byte no-op. `reader.get` answers in the same form: composite content-bearing fields project at each leaf (an `array<richtext>` reads as markdown strings rather than stored content objects) and a present-null reads `null`. `quill.resolve(doc)` becomes `reader.resolve()`. The storage DTO verbs name their lane: `toJson` / `fromJson` / `tryFromJson` / `loadJson` become `toStored` / `fromStored` / `tryFromStored` / `loadStored` (Python: `to_stored` / `from_stored` / `try_from_stored`), completing the family `getStored` started. `storageVersionOf` / `currentStorageVersion` are unchanged. Separately, **a content image draws nothing**: what a content image's `url` names is undecided, so the Typst backend lowers an `image` island to nothing and warns under a new `backend::declined_construct` family (per content field, `args` `{backend, construct, count}`, the field's `DocPath` in `path`) — a consumer routing on diagnostic codes gains a sixth warning family. A plate's own `#image("assets/…")` is unchanged, and the island still stores, round-trips and reaches an editor. A card the wire refuses now carries the diagnostic code its addressed mutator mints, so Python's `make_card` / `insert_card` raise `QuillmarkError` where a content violation used to be a bare `ValueError`. Python `edit::*` diagnostics anchor at the rooted `DocPath` WASM already carried, so `Diagnostic.path` reads `main.<field>` where `set_all` gave a bare name and `set` gave none. Stored blobs, the `schema` tag, and every byte these verbs write are untouched. A pruning sweep also lands: five retired `Quill.yaml` keys (`must_fill`, `enum`, `ui.order`, the `richtext(inline)` token, `markdown`) lose their tailored migration message and fail under serde's own text; a `ui.group` with no `ui.groups` registry is now a load error (`quill::implicit_group`), which a WASM or Python host never saw warned because `Quill::from_tree` drops config warnings; `pdfform::form_schema_version` retires, a `form@0.1.0` file failing as an unrecognised tag under `pdfform::invalid_form_json`; the CLI loses `render --verbose` and `schema`/`blueprint` `-o`, and `validate` reads `plate_file` from the loaded quill rather than the filesystem; a block-only island takes its own line in the model, `Content::normalize` performing the break `to_markdown` used to and `validate` stating it as `Invariant::BlockIslandNotAlone`, with every stored blob still loading. A quill also carries the load's advisory diagnostics now (`Quill::warnings()`, `quill.warnings` in WASM and Python), which closes #1625 and retires the two loader doors that existed only to return them (`Quill::from_tree_with_warnings`, `quillmark::quill_from_path_with_warnings`). It also retires fifteen `quillmark-core` / `quillmark-content` items with no caller (`Document::to_plate_json`, `card_kinds`, `IntoIterator for &Payload`, `MetaKey::ALL` / `is_root_only`, `PathStepWire` / `CommentPathSegment`, `YamlError::line` / `column` / `hint`, `RenderedRegion::contains`, `print_errors`, `Delta::apply`, `ChangeBundle::from_delta`), turns `normalize_document`'s unfilled `Result` into a `Document`, and adds `RenderError::coded_hint` and `region::nearest_region`; no binding surface changes. The crate-compatibility ceremony is withdrawn with it: `#[non_exhaustive]` leaves every type in the workspace, so struct literals and exhaustive matches compile out-of-crate again (`RenderOptions { .., ..Default::default() }` among them) and a `_` arm stops hiding a variant a build has not learned; the `Backend` seal and `quillmark_core::backend::sealed` are deleted and `Quillmark::register_backend` becomes private, so `Quillmark::new` — one backend per enabled cargo feature — is the whole registry, the one thing here that stops compiling; and `prose/canon/COMPATIBILITY.md`, a SemVer promise no CI job checked, is deleted. The pre-session `supportsCanvas` probe goes with them at every layer — `Quillmark::supports_canvas`, `quillmark_core::formats_support_canvas`, the WASM `Engine.supportsCanvas(quill)` and `LiveSession.supportsCanvas` getters, and the `canvas` key of a runtime `BackendDescriptor` — because it keyed on output formats while canvas paint is a `SessionHandle` seam a backend overrides independently of them; `LiveSession::supports_canvas()`, derived from that seam, stays, and a JS consumer opens the session and handles the throw `paint` / `pageSize` already owe a compile with nothing to paint. pdfform also drops its SVG and PNG output formats: `supported_formats` reports `[Pdf]`, so a render asking for either — `quillmark render --format png` among them — fails under `backend::format_not_supported`, and `RenderOptions::pages` on a pdfform quill now meets the `backend::page_selection_not_supported` PDF always gave. Canvas paint is untouched: `render_rgba` and `hayro` stay, and only `hayro-svg`, the SVG artifact path's one caller, goes. `RenderOptions::producer` goes too — the PDF `/Info` `/Producer` override no first-party caller set, plumbed through the engine, both bindings and both backends — while the stamp it overrode is unchanged: every rendered PDF still carries `Quillmark <version>`, defaulted once in `quillmark-pdf`'s `StampOptions::default()` rather than by a `default_producer()` per backend. The `$ext` namespace verbs collapse into the whole-map three: `storeExtNamespace` / `removeExtNamespace` / `getExtNamespace`, their Python twins, and the `Card::store_ext_namespace` / `remove_ext_namespace` they delegated to are deleted, leaving `getExt` / `storeExt` / `removeExt` (Python `store_ext` / `remove_ext`) with the `card` selector — a namespace write is `{...getExt(), [ns]: v}` on the client, and the one behavior the spread does not carry is the drop-when-empty a `removeExt` supplies. |
| [0.111 → 0.112](0.111-to-0.112.md) | One spelling per name in the canonical content: every vocabulary member carries its payload in `attrs`, built-ins included, where a built-in used to spell it in named siblings and only an unknown used the bag. Promotion stops being an encoding change, and four of the five mechanisms that bridged the two forms are deleted. The break is at the seam: a host reading `line.level` / `line.lang` / `mark.url` / `mark.id` or a list item's shape reads them under `attrs` now (the TS narrowing types move with them, so `typecheck` reports it), and the authored lane — `overwrite`, `install`, `CardInput.body`, the op wire — *rejects* the old spelling rather than reading it, so writes throw. **Stored documents need no migration**: the decoder reads the old spelling wherever it meets it, which is not a courtesy but the only thing that can work, since a `richtext` field rests as a content object inside an opaque payload value that carries no schema tag and no walk can safely find. Canonical bytes move (`attrs` on built-ins, and coincident marks reorder on a tie-break the wire now carries rather than a hand-assigned ordinal), so content hashes recompute once; generated Typst nests coincident wraps the other way, identical glyphs, moved goldens. The storage tag becomes `quillmark/document@0.112.0`. |
| [0.110 → 0.111](0.110-to-0.111.md) | A fix release: four surfaces refuse input they used to accept and produce something wrong from. The one break that can stop a render is a **pdfform background that was never stripped** — `form.pdf` is documented as carrying no form of its own, and the backend wrote a fresh `/AcroForm` onto it without looking, leaving a second `/AcroForm` key on the catalog and the old widgets live in the page `/Annots`. That is refused (`pdf::existing_acroform`), on the PDF lane only; SVG and PNG draw values and are unaffected. So is a non-finite widget rect (`pdf::bad_rect`), which pdf-writer printed verbatim into a PDF no number grammar admits. `LineOp::SetKind` refuses a heading level outside `1..=6`, a path naming no directory fails as `quill::load_failed` rather than pointing at the `Quill.yaml` it cannot be missing, and a `plaintext` field declared `inline: true` keeps the flag on the schema echo it was dropping. Additive: `mapMarks` / `Content::map_marks`, which answers where a `ChangeBundle`'s text-moving channels leave a field's marks so an editor diffs against the rule instead of reimplementing it. Documents and stored blobs are untouched. |
| [0.109 → 0.110](0.109-to-0.110.md) | The container discriminator becomes a field a type checker asks for on every write lane, not just the op lane. `Container::instance` tells one container from an adjacent sibling of identical shape, and 0.109 left it an obligation with no signal on `overwrite` and `CardInput.body` — the lane a codec flattening a tree writes through. It could not be otherwise: one encoder served storage and the bindings, writing the key only where it was non-zero, and a field a read may omit is a field a write cannot require. `serial::to_seam_value` is that encoder with every `instance` spelled, and the bindings take it on every lane typed `Content` (`reader.getContent{,At}`, `getStored` on a body, `importMarkdown`, `rebase`, and the card wire behind `document.main` / `cards` / `card(i)` / `removeCard` / `makeCard` / `seedMain` / `seedCard`). **`ContentContainer.instance` becomes required**, `ContentContainerInput` is deleted, and `LineOp.setContainers` takes `ContentContainer` — a smaller surface than 0.109's. The break is every hand-built container literal, and it is the one a type checker does report. What it still cannot report is a `0` stamped on every run, which is the write that welds them: `assignInstances` is the rule, not the type. Content parsed from a stored document is the one shape that needs a cast. Storage keeps the omission and stored blobs re-encode byte for byte; so do the render lanes, and so does what the seam types `unknown` (`getStored` on a field, `payloadItems`), which answers with the stored bytes verbatim. Documents are untouched, and the Rust and Python libraries gain `to_seam_value` without losing anything. |
| [0.108 → 0.109](0.108-to-0.109.md) | Two holes close where a projection trusted what its types did not carry. **Canonical form becomes a type**: `Normalized` states that `normalize` has run, every codec returns one, and `to_markdown` / `emit_content` / `Card::body` / the typed readers take one — which closes a stack overflow that aborted the process (a SIGABRT no `Result` catches) on a content nested past `MAX_NESTING_DEPTH`. The token derefs to `&Content`, so a read-only consumer needs no change and a mutating one takes `into_content()` … `into_normalized()`. Deliberately weaker than validity: it promises canonical, not valid, so a projection taking one owes totality rather than trust. **Container identity gains `instance`**, the field that tells one container from an adjacent sibling of identical shape, which contiguity alone read as one — closing four defects, three of them visible in Markdown (the `<!-- -->` idiom no longer destroys the second list's marker, two adjacent ordered lists stop numbering 1 2 3 4, and a second list's `start` survives the round trip). Adjacent lists alternate their marker (`-`/`+`, `.`/`)`); `Quote` becomes a struct variant and `ListItem` / `Unknown` gain the field, so an exhaustive `match` needs `..`. Stored blobs re-encode byte for byte and the `@0.93.0` tag holds, since the key is written only where it does work — but a 0.108 reader ignores it and welds the two runs, which is the one direction that costs. Separately: **a container inside a list item no longer terminates the list** in the Typst lowering, `.quillignore` reads `*` as gitignore does (so `assets/*` stops covering `assets/icons/logo.png`), a document body that `validate` refuses is refused on write instead of discovered on read, `PdfUpdate` takes an `ObjectIndex` (a 20-page form stamps in 0.7 ms rather than 37 ms), and the three op-wire *encoders* are removed — no product path executed them. Additive: `quillmark_content::traverse`, `RenderError::coded`. Documents are untouched. |
| [0.107 → 0.108](0.107-to-0.108.md) | A **cell** holds a value and cuts the commitment ladder for it; a **namespace** holds cells and is what they compose to. Leaves and `array` are cells, a typed dictionary and a variant's field set namespaces. Two rules follow, and both break quills that loaded before. A literal is declared where its cell is, so a `default:` / `example:` on a typed dictionary is a load error (`quill::{default,example}_on_namespace`) naming the properties that hold it — the variant container's existing rule generalized. And absence is inherited rather than terminal, so an absent container reaches each property's own `default:` at any depth: a **render-output change** for any quill declaring one under a container a document may omit, and the fix for three disagreements at once (`contact: {}` rendering what omitting `contact` did not, a container `default:` crossing whole and leaving a declared property missing from the plate, and `default: {}` emitting a keyless `{}` against its own documentation). Separately, `must_fill:` is retired: obligation is a reading of `default:`'s absence, never a declaration of its own, and declaring the key is a load error (`quill::field_parse_error`) naming the migration that field's shape takes. Four of five shapes migrate by deletion; `must_fill: true` beside a `default:` is the one behavior deleted and the one judgment call — keep the `default:` to render unasked, or move it to `example:` to keep the ask, in which case an untouched document renders the blank rather than asserting a value nobody chose. Quieter consequences: `resolve()` reports a container's strongest contributing rung where it reported `blank` while rendering defaults, seeding descends into a container to reach a property's `example:`, and `quillmark:must_fill` leaves the transform schema, which is the wire *validity* contract. `FieldSchema.must_fill`, `QUILLMARK_MUST_FILL_KEY` and the WASM `QuillFieldSchema.must_fill` go with it. Stored documents are untouched, and no in-tree quill declared either refused shape. |
| [0.106 → 0.107](0.106-to-0.107.md) | A declared type means the same thing at every depth: every type nests at every position the schema admits, lowering dispatches on the schema node beside each value rather than on tables of top-level names, and one address tree answers what a plate may address on either backend. Lead with the break no type checker reports: **a plate read of a typed-table row cell regions on the cell**, so `#data.refs.at(0).org` regions as `main.refs[0].org` where it regioned as `main.refs` — a wrong address, not a missing one, routing a click on one cell to the whole table. Two schema literals that loaded before now fail **load**: a nested `richtext(inline)` `default:` / `example:` over one paragraph (`validation::not_inline`), and a container-shaped literal on a variant-bearing enum (`quill::default_type_mismatch`). A `date` lowers to a **native** `datetime` — `.value` and the paren `display` form are hard compile errors — and `display(field, ..)` places its clickable ink by schema address instead. A nested `date` / `richtext` / `plaintext` reaches the plate as its declared type where it arrived as a bare string or as internal canonical-content JSON. `plaintext(field)` is removed, having never acquired a caller. Widenings: containers nest freely (`quill::nested_object_not_supported` and `quill::nested_array_not_supported` are gone), a variant cell carries any type (`quill::variant_field_type` is gone), a row property is a writable address on either backend, `blueprint()` expands a container at every depth, a `default:` reaches the plate from every position it can be declared in, a single-assignment `let` alias keeps its address, and `VARIANT_DISCRIMINANT_KEY` joins the WASM runtime exports. Stored blobs and the document syntax are untouched. |
| [0.105 → 0.106](0.105-to-0.106.md) | A schema address may step one property into a declared container, and an `enum` may declare `variants:` — a per-member field set that exists only in the world where the discriminant holds that member. Lead with the break no type checker reports: **region addresses shift**, so a plate reading `#data.classification.poc` regions as `main.classification.poc` where it regioned as `main.classification`. The step is gated twice — a property the container *declares*, read directly off `data` — and `doc.pathFor` mints the address a consumer would otherwise spell by hand. `variants:` is the one key that changes a field's resting shape, from a bare string to `{value: <member>, …that member's fields}`, so a plate reads `data.<field>.value` for the discriminant and every cell of the live world unguarded inside the `values ∪ blank` branch it already owes. `usaf_memo`'s four `cui_*` fields move under `classification`'s `CUI` variant, a break that fails quietly: the stale keys draw no diagnostic and simply stop being read. `EditError::UnknownField` becomes a struct variant carrying the in-field path, and an undeclared property anchors at `main.address.zip` rather than at the field. Additive: `field-region(field, body)`, `font` / `size` / `align` on `form-field`, `FieldSchema::variants` and `variant_field`, `VariantFields` and `VARIANT_DISCRIMINANT_KEY`. Stored blobs are untouched, and a quill declaring no variants projects identically at every surface. |
| [0.104 → 0.105](0.104-to-0.105.md) | A field's blank becomes a property of the field rather than a member of its type's domain. An `enum`'s blank is `""`, reserved and outside `values:`, so an absent no-`default:` enum renders blank instead of borrowing `values.first()` — a choice nobody made, previously reachable from a cosmetic `values:` reorder. The accepted domain widens to `values ∪ blank` for **every** enum, not only defaultless ones, so an authored `""` now clears the gate and reaches the plate: a plate branching with `else` silently renders a variant nobody chose, and `data.at(key, default: X)` is not a guard because every declared key is always present at render. `date` / `datetime` coercion stops mapping `""` to null, so a blank date outranks a `default:` exactly as `""` already did for `string`. Declaring `""` in `values:` is a load error (`quill::enum_blank_member`) while `default: ""` stays valid and unchanged. `zero_value` → `blank`, `FieldSource::Zero` → `Blank`, and the wire token `"zero"` → `"blank"`. Separately, obligation leaves `default:` for its own `must_fill:` key, deriving `default.is_none()` so no quill needs editing, and `Quill::validate` gains a schema-side trigger that warns on a cell the schema obliges and the document never authored — so a merely incomplete document no longer validates clean, and a consumer reading "any diagnostic means not done" changes verdict on documents that did not change. Authoring the blank discharges the obligation where `null` does not, the one place `null ≡ absent` stops carrying. Additive: `must_fill:`, `ui.blank_title`, `quillmark:must_fill` and `quillmark:blank_title`. Stored documents are untouched. |
| [0.103 → 0.104](0.103-to-0.104.md) | The `enum:` modifier on `type: string` retires: `type: enum` with a `values:` list is the one spelling of a closed string domain, and `enum:` on any type is a load error whose message names the replacement. `QuillConfig::schema()` re-emits every domain as `values:` (the WASM `QuillFieldSchema.enum` field is gone), and the transform schema now carries a domain it was silently dropping, so a generated validator rejects out-of-domain values it used to accept. Separately, geometry addresses parse segment-wise: `RenderedRegion.field` / `FieldRegion.field` / `ContentHit.field` spell an array element bracketed (`main.references[0]`), the spelling `Diagnostic.path` already uses — and `locate` / `fieldBoxes` answer for a deeper-than-one-segment address for the first time, which was dead for every `array<richtext>` element and every nested pdfform key. `to_markdown` writes `***` for a thematic break, so a rule as a bullet item's first block survives the round-trip instead of losing its item. `@quillmark/wasm` moves its `engines` floor to Node 24. Additive: `doc.pathFor` / `doc.cardPath`, and a quill declaring the block constructs its plate does not typeset, which raises the new `plate::unsupported_construct` family. Stored blobs and rendered output are untouched. |
| [0.102 → 0.103](0.102-to-0.103.md) | WASM: `init()` resolves to the core surface instead of `void`, and `Quill`, `Document` and the free functions leave the static exports: destructure them from `await init()`. The gate becomes the only way to obtain one, so the pre-init mistake stops being expressible and `runtime::not_initialized` retires with the door it guarded. `Engine`, `MAIN_CARD_ADDR`, `isQuillmarkError` and the open-set guards are unchanged, as are the `Quill` / `Document` **type** exports. CLI: `quillmark render --verbose` writes its progress lines to stderr, so `--stdout` no longer frames the artifact with them. Documents, stored blobs, and the Rust and Python libraries are untouched. |
| [0.101 → 0.102](0.101-to-0.102.md) | The pre-1.0 vocabulary reset. `install*` → `overwrite*`, writer `setBody` → `reviseBody` (now returning the receipt), `LiveSession.apply` → `update`, `getMarkdown` / reader `getBody` → `bodyMarkdown`, `store/removeSeedNamespace` → `*SeedOverlay`, `schemaVersionOf` → `storageVersionOf`. The `edit::*` codes for content-field failures rename and gain a `codec` arg, so one code covers both codecs; `richtext::not_inline` becomes `validation::not_inline`. Documents and stored blobs are unaffected. Separately, island-id minting splits by case: restoring a deleted island re-lands the id it was deleted under, and the island channel states two contracts it previously left to the implementation. `@quillmark/wasm` ships `--target web`: `await init()` is required before first use, and the bundler plugins the package used to demand are gone. |
| [0.100 → 0.101](0.100-to-0.101.md) | Two Rust constructors leave the published surface: `Document::from_main_and_cards` becomes crate-internal (its invariants were `debug_assert`s feeding a release-build panic), and `QuillConfig::from_yaml` is removed for `from_yaml_with_warnings`, which keeps the structured diagnostics the boxed string destroyed. The change-bundle verbs take one `ChangeBundle` struct in place of three positional op arguments, because the bundle gains an island channel: `IslandOp` edits an island's payload or inserts one with its slot, so a table or image edit keeps the field's identity anchors instead of falling back to a whole-field `install`. On the bindings the channel is additive (`applyChange`'s new optional `islandOps`); documents and stored blobs are unaffected. |
